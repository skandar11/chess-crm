# Инструкция для администратора — ChessCrm.Bot

_Версия 1.0 | Март 2026_

---

## Как работает бот

Пишешь в Telegram обычным текстом — бот понимает смысл и спрашивает подтверждение перед записью. Никаких команд со слэшем, никакого формата — пиши как привык.

**Три шага любой операции:**
1. Ты пишешь запрос
2. Бот показывает превью — что он собирается сделать
3. Ты нажимаешь ✅ или ❌

---

## Кнопки

| Кнопка | Что делает |
|--------|-----------|
| ✅ Да, записать | Подтверждает операцию, бот записывает в базу |
| ❌ Отменить | Отменяет, ничего не меняется |
| ✏️ Добавить данные | Режим дополнения — пишешь недостающее, бот пересобирает превью |

## Команды

### 1. Новый ученик

```
Новый ученик Попов Богдан, 04.11.2019, мама Иванова Светлана 7771234567, начинающий, вт18
```

Обязательно только фамилие. Остальное — по возможности.

**Что можно указать:**
- ФИО: `Попов Богдан` (фамилия + имя)
- Дата рождения: `04.11.2019`
- Родитель 1: `мама Иванова Светлана 7771234567`
- Родитель 2: `папа Попов Сергей 7779876543`
- Уровень: `начинающий` / `средний` / `продвинутый`
- Группа: `вт18` (или `вторник 18:00`)

Если что-то не указал — нажми ✏️ и допиши:
```
дата рождения 12 мая 2018
```
```
мама Жанар 7771112233
```

---

### 2. Абонемент

```
Айгерим оплатила 15000 за апрель
```
```
Попов Богдан 12000 за март Никите
```

**Что извлекается:**
- Имя ученика
- Сумма (только цифры)
- Месяц (если не указан — текущий)
- Получатель: `Никита` или `Квитко` → Никита Квитко; `Нурсултан` или `Бурцев` → Нурсултан Бурцев

---

### 3. Записать в группу

```
Записать Попова в среду 18:00
```
```
Записать Айгерим в пн16
```

**Формат группы:** 2-буквенный день + час — `пн16`, `вт18`, `ср16`, `сб10`, `вс12`

Полные формы тоже работают: `понедельник 16:00`, `суббота 11:00`

---

### 4. Убрать из группы

```
Убери Попова из пн 16:00
```
```
Иванова больше не ходит на вт18
```
```
Выписать Айгерим из среды 18
```

---

### 5. Перенос в другую группу

```
Перенеси Попова из пн16 в ср18
```
```
Переведи Айгерим с вторника на четверг 16:00
```

Если ученик в одной группе — источник можно не указывать:
```
Перенеси Попова в ср18
```

---

### 6. Редактировать данные ученика

```
Измени телефон Попова на 7779998877
```
```
Поменяй уровень Айгерим на средний
```
```
Деактивировать Иванова
```

**Что можно менять:**
- `birth_date` — дата рождения (формат ДД.ММ.ГГГГ)
- `parent_name` / `parent_name_2` — имя родителя
- `parent_phone` / `parent_phone_2` — телефон родителя
- `level` — уровень ученика
- `notes` — заметки
- `is_active` — активен / неактивен
- `subscriptions_count` — количество абонементов

**Нельзя менять:** ФИО ученика (full_name). Для этого — только вручную в базе.

---

### 7. Инвайт для родителя

```
Инвайт для Попова
```
```
Сгенерируй ссылку для Айгерим
```

Бот создаст одноразовую ссылку действительную 24 часа. Ты копируешь и отправляешь родителю напрямую.

---

### 8. Аналитика

Любой вопрос о данных — бот сам генерирует SQL и отвечает:

```
Кто не платил в этом месяце?
```
```
Сколько учеников у Квитко?
```
```
Список учеников группы вт18
```
```
Сколько всего абонементов продано в марте?
```
```

```
```
Кто записан в несколько групп?
```
```
Ученики без даты рождения
```

## Формат групп

| Сокращение | Полная запись |
|-----------|--------------|
| `пн16` | понедельник 16:00 |
| `вт18` | вторник 18:00 |
| `ср16` | среда 16:00 |
| `чт16` | четверг 16:00 |
| `пт16` | пятница 16:00 |
| `сб10` | суббота 10:00 |
| `сб11` | суббота 11:00 |
| `вс12` | воскресенье 12:00 |

## Что бот пишет в базу, а что — только в таблицу

| Операция | PostgreSQL | Google Sheets |
|----------|-----------|--------------|
| Новый ученик | ✅ | ✅ Лист «Ученики» |
| Абонемент | ✅ | ✅ Лист «Абонементы» |
| Инвайт | ✅ | ✅ Лист «Инвайты» |
| Запись в группу | ✅ | ❌ |
| Убрать из группы | ✅ | ❌ |
| Перенос | ✅ | ❌ |
| Редактирование | ✅ | ❌ |

Источник правды — PostgreSQL. Google Sheets — зеркало для твоего удобства.

---

## Частые ошибки и как их избежать

| Ситуация | Что делать |
|----------|-----------|
| Бот нашёл несколько учеников | Уточни полное ФИО |
| «Ученик не найден» | Проверь написание, попробуй только фамилию |
| «Группа не найдена» | Уточни день и время в формате `пн16` |
| «Абонемент за этот месяц уже есть» | Дубль — нормально, просто предупреждение |
| Бот написал неправильное превью | Нажми ✏️, допиши исправление |

---

## Что бот никогда не делает

- Не удаляет записи из базы (только вручную)
- Не изменяет ФИО ученика
- Не пишет в Google Sheets при групповых операциях
- Не выполняет операцию без твоего подтверждения через ✅
